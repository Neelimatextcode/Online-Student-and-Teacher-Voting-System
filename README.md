School Election Voting System

This is a web-based voting system designed for students and teachers, built using HTML, CSS, and JavaScript. 
It allows users to securely cast votes with a photo-based candidate selection for multiple positions, including Head Boy/Girl, Deputies, and House Captains.
Voters can review their selections before submission, and an admin panel enables downloading results in Excel format and managing votes. 
Future enhancements can include admin authentication, cloud database integration, and visual charts for election results.
